# Production source baseline

The source for Vercel deployment `dpl_4SFrDjCbvToxvgeAWgfXtsN85rKp`, aliased to munigan.app, was recovered on 2026-09-11 before releasing the iterations control. Earlier website releases had been deployed directly from uncommitted files.

All 380 retained deployment files were verified against the SHA-1 values returned by Vercel. Existing matching local files were reused; 33 differing files were recovered from that deployment. Generated caches, screenshots, experiment artifacts, and environment files were excluded. Next.js may regenerate its environment type declaration during verification.

This baseline tracks the existing live application, including the localized shell, settings, per-item enhancements, and existing Raid Trainer. Newer unfinished navigation and Raid Trainer edits in the development checkout were not included.

Validation: frozen dependency install, 234 unit/UI tests, ESLint, TypeScript through the production build, and the production build passed.
