# PostHog Implementation Plan

> Execute inline with verification at each boundary.

**Goal:** Measure daily traffic, Gear Lab activation and PRO interest on PostHog's free plan.

**Architecture:** Explicit browser events and normalized page views; successful run admission and PRO membership confirmed by API routes, delivered after the response. Internal account IDs only; anonymous SDK IDs link visitor events. No recordings, autocapture, raw imported data, report capabilities, or query strings. Missing configuration disables analytics. Server events use stable UUIDs for retry deduplication; analytics failure cannot fail a product action.

**Tech Stack:** Next.js 16.3.4, posthog-js, posthog-node, Vitest, Playwright.

**Spec:** User-approved analytics proposal in this conversation: traffic, Gear Lab and PRO conversion, free plan only.

## Tasks
- [x] Add tested URL/event property allowlist and fail-open client/server adapters.
- [x] Mount page/identity tracking in AppDocument; instrument import, simulation requests, PRO opens and sign-in intent. Instrument accepted jobs and confirmed memberships after successful API operations.
- [x] Configure project token and host in deployment environment; keep local/preview tracking off by default, no payment method, no session replay.
- [ ] Verify privacy, disabled behavior and failure isolation with unit tests; run component tests, typecheck, lint, build and browser checks. Deploy and confirm received events.
- [ ] Configure dashboards for daily traffic, Gear Lab adoption and PRO interest; verify free billing state and document event semantics.

## Verification contracts
`safePath('/reports/secret?token=x') === '/reports/:token'`.
Unknown routes become `/other`. Event properties use a closed allowlist; unknown events are dropped.
`captureServer` resolves even when transport rejects, and deterministic event UUIDs remain stable across retries.
No environment token means no network requests. Production-only browser enablement excludes localhost/preview by hostname.
