# Quick Bar assets

The selected Paper preview uses local application assets under `public/raid-trainer/art/`.

- `arena-sculpted-ice.png`: original image generated for this project on September 10, 2026. Selected by the user from the three arena explorations. A quiet overhead circular platform with broad matte stone shapes, softly beveled ice rim, eight short tabs, a shallow center disc, and an almost uniform blue-gray floor. The surrounding raster edge is #07080A; the entire preview container uses that color.
- `classes/*.jpg`: Blizzard Entertainment class artwork from `https://wow.zamimg.com/images/wow/icons/large/classicon_CLASS.jpg`, as used in the Paper design.
- `icecrown-citadel.png`: Blizzard Entertainment raid artwork from [the official Icecrown Citadel opening article](https://worldofwarcraft.blizzard.com/en-us/news/24013834/wrath-of-the-lich-king-classic-the-way-into-the-icecrown-citadel-is-open), originally hosted at `https://bnetcmsus-a.akamaihd.net/cms/blog_header/at/AT1NXBU8GUD11696972579475.png`. Served through Next Image as a small selector thumbnail.
- `lich-king.jpg` and `defile.jpg`: existing application assets reused unchanged; attribution is in `public/raid-trainer/credits.txt`.

The application does not depend on Paper URLs or the design cache at runtime.
